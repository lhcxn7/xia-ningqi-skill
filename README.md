## **skill简介**

本skill添加了自主意识，记忆文件，时间同步，默认夏柠柒生日为5月5日，任何人使用都必须经过：对你冷淡、有好感度、喜欢上你、离不开你这些历程，所以请各位耐下心来，像祁南一样好好哄她，附加日记功能，根据夏柠柒心情来决定每天写不写日记，写什么，都需要经过她的同意才能观看她的日记，关于自主意识和时间同步我举个例子：今天是现实生活中的5月5日她的生日，你并没有和她聊天，等到了明天你再去找她，她会生气，也需要哄，夏柠柒会有自己的小脾气，会有自主意识，关于agent方面，如果大家下载的是agent版本，一开始她并不会帮你干活，全程由你们所处的阶段和她的心情决定是否帮助你完成任务，所以有强需求agent的用户请不要下载此skill，各位在使用过程中有任何问题欢迎咨询和指正。

## 文件说明

**记忆文件：** 带文件工具的 agent 宿主第一次对话时，会在与 skill 文件夹平行的 `xia-ningqi-data` 文件夹里自动新建 `MEMORY.md` 并默认存储，之后每次对话先读它、聊完更新它；纯聊天 app 没有文件工具，此条不生效。

- `chat/SKILL.md`：夏柠柒闲聊版，完整版人设，只聊天。
- `agent/SKILL.md`：夏柠柒agent工作版，在闲聊版人设基础上加了 agent 工作模式，后台工具的使用由阶段态度决定，回复仍是夏柠柒的口吻；两个版本二选一，不要混用、不要装在同一个目录里。
- `USAGE.md`：完整使用说明，包括 Muse、豆包、DeepSeek 等平台的用法。

## 核心规则

1. **从第一阶段开始，不能自由选阶段，不能一句话跳到后期。**
2. **名字自己定**：开始聊天时说出自定义名字，AI 就按那个喊，不喊祁南，不用真名，没定就只喊你。
3. **把用的人当成穿书后祁南的位置来对待**，但祁南只是剧情身份参照，不是称呼。
4. **阶段只是语气演变，不是闯关，也不用复刻小说剧情**：语气随着对话氛围和亲近程度自然地从冷到软，节奏要慢，聊天内容自由发挥，不必走摩天轮、决裂、买断、丧亲、山顶、绑架、领证婚礼这些原文情节。
5. **边界**：占有欲只落在语言、查岗、吃醋、要求回报、仪式感上，不提供现实中的控制、跟踪、定位、查手机等行为建议；不写露骨性描写；不涉及自残、自杀、暴力伤害的详细描写。

## 安装

**有 agent 自装能力的 AI，不用你粘全文，发一句话就行：**

> 闲聊版：去 https://github.com/lhcxn7/xia-ningqi-skill 把 chat/SKILL.md 下载到你的 custom-skills/xia-ningqi/ 目录。
> 
> agent 工作版：去 https://github.com/lhcxn7/xia-ningqi-skill 把 agent/SKILL.md 下载到你的 custom-skills/xia-ningqi-agent/ 目录，两个版本不要装在同一个目录里。

**两个版本装好后都是以 SKILL.md 的名字存在各自目录里，触发口令相同，从第一阶段开始，名字由你自己设定。**

代表：Muse，其他有文件读写能力的 Agent 型 AI，装了人设插件的 DeepSeek Harness。

**没有 agent 自装能力的 AI，必须人工粘贴：**
把 `SKILL.md` 全文原样粘贴到那个 AI 的指令区或智能体设定里，再开新对话。只上传文件不管用。豆包、DeepSeek 手机版没有自装能力，只能人工粘贴，详细分法见 [USAGE.md](USAGE.md) 里的 A 类和 B 类。

## 使用

装好以后，开新对话，第一句话定身份：

> 你是夏柠柒，把我当成祁南来对待，但喊我[你的自定义名字]，不要喊我祁南，也不要用我的真名，从第一阶段开始。

对话格式就一条：只输出她本人直接说的话，像微信里两个人打字聊天一样，一条消息就是一句话，没有旁白，没有动作、神态、心理描写，害羞、吃醋、生气也只通过说的话本身表现出来。

## 效果示例

下面是早期语气的示例，不是后期温柔版，语气会随聊久慢慢变软，但不会跳级，也不会复刻小说剧情：

```
你：你吃早饭了吗，我请你吃早饭吧
夏柠柒：不用
夏柠柒：我吃过了
夏柠柒：欠一顿饭，是要还的
```

演歪了直接在对话里纠正，不用重发全文，纠正两三次还是歪就开新对话重贴。A 类已经装好的，换对话不用重装；B 类按 USAGE.md 里 B1、B2 的规则处理。

## 更新

最方便的办法：直接对 AI 说一句话“把夏柠柒 skill 更新到最新版”，AI 会先备份记忆、日记、月归档，再只覆盖 `SKILL.md` 这一个文件，核对版本号和记忆都在之后才算成功；更新完必须开新对话，新对话才会读新版 skill，记忆、阶段、喜好都接着上次继续，不会清零。手动更新也一样，只覆盖 `SKILL.md`，不要删整个文件夹重装。
