# 夏柠柒人物数据库

## 这是什么

夏柠柒的 canon 数据库：把《穿书反派，把阴湿女主养成病娇了》（作者：二次元的猫，
番茄小说 ID 7645556324868049945，全书约 62 万字、1–312 章）的原著底子，
从散落的语料总结里抽出来，结构化、可查询地存成一套 JSON。
（苦读书站内 312 之后仍有真实 313，本库覆盖 1–312 章。）

**一句话定位：skill 是行为规矩，数据库是 canon 证据。**

| | skill（`SKILL.md` v2.5） | 本数据库 |
|---|---|---|
| 管什么 | 她怎么说话、按什么阶段走、什么绝不能做 | 她是谁、说过什么、做过什么、按什么顺序变的 |
| 形式 | 行为规则 + 浓缩刻画，一次读进上下文 | 结构化条目，按需查那一格 |
| 读法 | 每轮对话都生效 | 需要时检索，不常驻上下文 |
| 能替代对方吗 | 不能 | 不能 |

没有数据库，skill 也能聊，但 canon 细节全靠浓缩版的印象，容易编；
没有 skill，光有数据库就是个维基，背得出她说过什么，当不了她。

## 怎么查

查询工具 `query.mjs`，Node 标准库 only，不联网，不写文件：

```bash
git clone https://github.com/lhcxn7/xia-ningqi-skill.git
cd xia-ningqi-skill/character-db/xia-ningqi

node query.mjs 吃醋                        # 关键词搜
node query.mjs 定位器 --type events         # 只查事件
node query.mjs 摩天轮 --stage mid           # 按阶段过滤
node query.mjs 阿嫲 --type lines --limit 5  # 按类型 + 条数
node query.mjs --type lines --chapter 107   # 无关键词，按章节列出
node query.mjs --chapter 131-165 --emotion 吃醋
node query.mjs --chapter 151a               # 重号章节用 151a / 151b
node query.mjs 撒娇 --addressee 祁南 --json # 机器可读输出
node query.mjs --stats                      # 各集合条目数
```

排序：关键词命中权重（`tags` > `text` > 其余字段）+ 短语整词加分，
按分数降序、同分按章节升序。

## 边界（硬规矩）

1. **全部意译、浓缩。** 所有 `text` 字段都是对原著台词/内心的凝缩意译，
   标 `paraphrase: true`。任何条目都不许写成她的原话，也不许当作 verbatim 引用。
2. **小说剧情绝不能当成跟 skill 使用者的共同经历。**
   `key_events` 只当背景参考；skill 的铁律（剧情不进对话）照样管着这个库。
3. **缺口老实标在 `flags.json`，不许编：**
   - 第 173 章永久缺失（目录 172 直跳 174），不编造；苦读书目录标示的 173 章实为真实 273 章，不是缺失的那章，见 flag-11；
   - 母亲名字三种写法并存，不得自行统一：沈婉萍多数（267、270、293、295、297、308、309、310、311 章）、苏婉萍仅 282 章、夏婉萍仅 277 章；父亲名字同样不统一，夏清河（295、297、309 章）、苏清河仅 298 章；本库以沈婉萍为准作多数写法约定，见 flag-02；
   - 210 章夏家施压是否由她亲自授意，文本未明示，不当作定论；
   - 未核实的 v2.3 遗留全部标 UNVERIFIED：捐款 567 万、黑丝腿照、
     谭雪约喝咖啡、点《江南》、海盗船被整、羊绒围巾连夜赶工，
     等用户定夺，本库不把它们当定论写进任何集合；
   - 镜像用字不一致（叶安冉/孟诗雨/李兆年等）已归一，见 flags；
   - 酒馆人名混乱（288 章宋瑶/宋晶、290 章宋玉、291 章宋瑶为叶安苒母亲，
     宋晶又兼歌手与投资人），不自行统一，见 flag-19；
   - 苦读书站内 312 之后仍有真实 313（商业帝国），仅标题核验、未读，
     不纳入 1–312 的小说正文覆盖，见 flag-20；婚礼仅在 310 章定下
     5 月 20 日，未办，旧说“312 章婚礼完结”已按实读纠正；
   - 283 章存疑一句（疑为叶安苒，未计入），见 flag-21；
   - 初版语料缺口大（多批只读了部分段落或只读开头），本库以浓缩版
     pass 总结为准，不谎称逐字背诵；211–230 章已由 pass5d 逐句补读填补，
     存疑 8 处见 flag-17（5 处已按 pass5e 回查定论，见 flag-17）；
     231–264 章已由 pass5e 逐句补读填补，存疑 7 处见 flag-18（说话人
     归属不明等，未擅自定论）；265–312 章已由 pass5f 逐句补读填补，
     两处定论见 flag-11、flag-02。
4. **不碰的东西：** skill 文件、记忆插件（`~/workspace/memory-plugin/`）、
   GitHub 仓库，本库只读料源、不改它们；查询工具不联网。
5. **本库不含任何用户个人信息。**
